🎓 HOW TO USE THE NEW ASYNC HELPER:

Replace this (OLD - blocks UI):
  response = requests.get(f"{API_BASE_URL}/api/patients/")
  
With this (NEW - non-blocking):
  self.api.get(
      url="/api/patients/",
      on_success=self.on_data_loaded,
      on_error=self.on_error,
      use_cache=True,    # ← Caching!
      cache_ttl=300      # ← 5 minutes
  )

Invalidate cache after updates:
  self.api.invalidate_cache('/api/patients/')
