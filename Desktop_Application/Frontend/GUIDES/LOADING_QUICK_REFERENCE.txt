def _on_error(self, error_msg):

    Toast(self, error_msg, icon_path="Icons/warning.png").show_toast()


═════════════════════════════════════════════════════════════════════════════════
KEY PARAMETERS EXPLAINED
═════════════════════════════════════════════════════════════════════════════════

show_loading: bool = True
  → Shows loading modal during API call
  → Modal auto-hides when done
  → Only shows if request takes >500ms

loading_title: str = "Loading..."
  → Main message shown to user
  → Should be specific and action-oriented
  → Example: "Loading patients..." not just "Loading..."

loading_subtitle: str = None
  → Optional secondary message
  → Provides more context
  → Example: "Please wait while we fetch the patient list"

═════════════════════════════════════════════════════════════════════════════════
TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════════

Problem: Modal doesn't appear
Solution:
  ✓ Check show_loading=True is set
  ✓ Check request takes >500ms (throttle network to test)
  ✓ Check loading_overlay.py exists

Problem: Modal doesn't disappear
Solution:
  ✓ Check success/error callbacks are called
  ✓ Check callbacks return properly
  ✓ Check network connection

Problem: App still freezes
Solution:
  ✓ Make sure you're using self.api (not requests)
  ✓ Check previous requests are still being used
  ✓ Search for "requests.get" to find blocking calls

Problem: Modal shows for fast requests
Solution:
  ✓ Check request is cached
  ✓ Check cache_ttl is set properly
  ✓ Test with DevTools throttling
